# 任务目标与数量来源核对（2026-10-07）

本记录回答“已有任务目标和数量怎样得来”，不代表全部任务流程已经完成或部署。

## 已核对的原始来源

- `tools/gen_quest_objectives.py` 的历史实现读取 `Localization/en_us/Text/Quest/<ID>.dat` 的 `Objectives`，解析目标名称和数量。
- `Text/QuestMonster.dat` 提供任务界面使用的怪物名称与 ID。该 ID 不等于世界中的怪物实例 ObjectId；当前服务端击杀匹配使用地图与名称，名字缺失时才使用位置范围。
- `Settings/Sys/Quest.xml` 提供等级、NPC、目标地图和提示坐标。本次核对的行没有直接给出所需击杀数量。
- `Text/QuestItem.dat` 提供收集目标的显示 ID。收集数量同样核对任务文件全文；已验证的参考帧能校验显示字段。任务 UI 收到的目标 ID、数量和进度是服务端报文中的独立字段，不能把 UI 显示数字当作本地文本中必然存在的数字。

## 已发现并纠正的提取问题

历史 `parse_objectives` 会在缺少数字时默认数量1。默认值不能作为客户端明确要求的证据。当前击杀生成入口保留已有313条目标规则，新增规则从核对后的字段提取，不再使用旧解析器的缺数默认值生成新增击杀数量。捕捉目标也逐个验证数量来源。

新增数量核对顺序为：中文 Objectives → 中文 Details、QuestText、IncompleteText 中紧邻已确认目标名的数量 → 英文 Objectives 中同目标的明确数量。仍找不到时，仅使用用户授权的相近等级任务数量，并记录参考任务 ID。推定的数量不再用作其他任务的数量参考。

新增目标须对应客户端名称表中的明确条目。任务标题、附近刷怪、故事含义不用于选择目标；多目标的顺序依据原文出现顺序，避免名称表顺序误配坐标。不能唯一对应的目标列入未解决清单，不能自动变成对话完成。
